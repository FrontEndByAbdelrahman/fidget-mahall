# Fidget Mahall

متجر إلكتروني لبيع ألعاب الفيدجت (Fidget Toys) 


## التقنيات المستخدمة

- React 19
- Vite
- React Router
- CSS (Vanilla)

## التشغيل

```bash
# تثبيت المكتبات
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build

# معاينة البناء
npm run preview
```

## الأوامر المتاحة

- `npm run dev` - تشغيل سيرفر التطوير
- `npm run build` - بناء المشروع
- `npm run lint` - فحص الكود
- `npm run preview` - معاينة النسخة المبنية
